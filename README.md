# Lok Bir Construction Pvt. Ltd. Website

A professional website for Lok Bir Construction Pvt. Ltd., a trusted construction company based in Bijuli Bazar, Baneshwor, Nepal.

## Features

- 🏗️ **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- 🎨 **Modern Styling** - Professional color scheme and layout
- 📱 **Mobile-Friendly** - Optimized for all screen sizes
- 🔗 **Quick Contact** - WhatsApp and phone call integration
- ✨ **Smooth Scrolling** - Smooth navigation between sections
- 🎯 **SEO-Optimized** - Meta tags for better search engine visibility

## Sections

1. **Home** - Hero section with company tagline and CTA buttons
2. **About** - Company information and mission
3. **Services** - Four main service offerings
4. **Team** - Managing Director information
5. **Contact** - Location, phone numbers, email, and WhatsApp chat

## Files

- `index.html` - Main HTML structure
- `style.css` - Responsive styling
- `script.js` - Smooth scrolling functionality

## Getting Started

1. Clone or download this repository
2. Add your logo as `logo.png` in the root directory
3. Add a background image as `construction.jpg` for the hero section
4. Open `index.html` in a web browser

## Deployment

To deploy on GitHub Pages:
1. Go to repository settings
2. Enable GitHub Pages from the main branch
3. Your site will be available at: `https://lokBirconstruction.github.io/Lok-Bir-Construction-PVT-LTD/`

## Customization

- Edit company information in `index.html`
- Modify colors in `style.css` (primary color: #0b2d5c, accent: #f4b400)
- Add or remove services in the Services section
